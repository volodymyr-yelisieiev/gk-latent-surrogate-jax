# AI-Assistance Review Record

The course requirements permit LLM assistance but leave responsibility for accuracy, originality,
citations, and final wording with the author. This draft was prepared with AI assistance from the
repository's source code, configurations, tests, retained experiment artifacts, the provided course
requirements, and primary literature.

Before submission, the author must:

- verify every scientific and numeric statement against the cited source or retained artifact;
- inspect every citation and ensure that it supports the surrounding claim;
- rewrite any passage that does not reflect the author's own understanding and intended voice;
- check that no confidential dataset information or unsupported provenance claim is disclosed;
- run an originality check appropriate to JKU policy;
- disclose AI assistance if the supervisor, institute, or current JKU rules require it; and
- retain this record privately unless an official disclosure format is requested.

This file is a review aid, not a substitute for an official declaration.
