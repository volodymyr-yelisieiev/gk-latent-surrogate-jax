        source commit: \texttt{f97a0257d7627c8ff896}\newline
        \texttt{0433aed30c750a9f90d5};
  \item test-evaluation tag: \path{experiment-seed52-evaluation-source};\newline
        source commit: \texttt{280540f54e67c0dbcae2}\newline

These tags expose the actual source snapshots; they do not turn the retrospective test into a
prospective locked test. Test metadata records the SHA-256 of an empty tracked diff; its dirty flag
refers only to the separately packaged untracked thesis tree.
The package supports Python
3.11 and newer, with Python 3.12 preferred.

\section{Portable Verification}

The following commands verify static checks, unit tests, the CPU synthetic pipeline, and package
construction:

\begin{lstlisting}[language=bash,basicstyle=\ttfamily\small,breaklines=true]
make install-dev
make check
make smoke-all
uv build
\end{lstlisting}

The smoke outputs are engineering fixtures and must not be interpreted as thesis-scale results.

\section{Principal Experiment Commands}

With the dataset root exported as \code{GK\_CYCLONE\_DATA\_ROOT}, the selected pipeline is:

\begin{lstlisting}[language=bash,basicstyle=\ttfamily\small,breaklines=true]
gks train-encoder \
  --config configs/experiment/server_encoder_simsiam_medium.yaml \
  --output-dir outputs/medium_seed52_reproduction/encoder
gks embed-dataset \
  --config configs/experiment/server_embed_dataset_medium.yaml \
  --override latent_cache.path=outputs/medium_seed52_reproduction/embed/latent_cache.h5 \
  --override latent_cache.encoder_checkpoint_path=outputs/medium_seed52_reproduction/encoder/checkpoints/step_000500 \
  --output-dir outputs/medium_seed52_reproduction/embed
gks train-sequence \
  --config configs/experiment/server_sequence_transformer_medium.yaml \
  --override latent_cache.path=outputs/medium_seed52_reproduction/embed/latent_cache.h5 \
  --override latent_cache.encoder_checkpoint_path=outputs/medium_seed52_reproduction/encoder/checkpoints/step_000500 \
  --override latent_cache.latent_normalization=cache \
  --output-dir outputs/medium_seed52_reproduction/sequence_transformer_cache_normalized
gks evaluate-rollout \
  --config configs/experiment/server_sequence_transformer_medium.yaml \
  --override training.max_steps=0 \
  --override data.split=val \
  --override latent_cache.path=outputs/medium_seed52_reproduction/embed/latent_cache.h5 \
  --override latent_cache.encoder_checkpoint_path=outputs/medium_seed52_reproduction/encoder/checkpoints/step_000500 \
  --override latent_cache.latent_normalization=cache \
  --override latent_cache.sequence_checkpoint_path=outputs/medium_seed52_reproduction/sequence_transformer_cache_normalized/checkpoints/step_000500 \
  --output-dir outputs/medium_seed52_reproduction/validation_transformer_cache_normalized
\end{lstlisting}

The same validation command is run for all learned candidates and persistence. After selecting the
cache-normalized Transformer by validation flux RMSE, only that checkpoint and persistence are
evaluated with \code{data.split=test}. The retained resolved configs are authoritative
for the exact arguments; the compact commands above communicate the pipeline rather than replacing
those records.

Each record names the evidence role, split seed, trajectory-manifest hash, aggregation, resolved
configuration, and local artifact hashes. Historical mixed-seed records remain labelled as
invalidated audit evidence and are not used for a thesis claim. These W\&B records do not contain
the complete original training telemetry required by the next protocol, and anonymous access has
not been verified from repository evidence. The test manifest was already inspected when this
retrospective report was prepared.

\section{Availability Boundaries}

Raw data and checkpoints are not distributed in the Git repository. Reproduction of the exact
medium experiment therefore requires authorized access to the preprocessed Cyclone/KvikIO dataset
and the retained ignored artifacts or retraining them from the documented configs. The synthetic
pipeline remains fully available from a clean checkout.
